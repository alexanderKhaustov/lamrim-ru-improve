# Формат правок

- Файлы с правками лежат в корне репозитория и называются по странице русского издания: `1079.md`. Markdown позволяет читать оформленный текст в GitHub.
- Один PR содержит правку одного законченного фрагмента — обычно предложения, реже абзаца. В PR её обсуждают, затем принимают или отклоняют по правилам [acceptance.md](acceptance.md).
- В файле страницы нет отдельного верхнего заголовка. Каждая правка оформляется блоком `<details open>` с `<summary>`: исходный оборот → предлагаемая замена. Номер страницы в заголовке правки не повторяется: он уже указан в имени файла.
- После `<summary>` и перед `</details>` оставляется пустая строка, чтобы GitHub обрабатывал Markdown внутри блока.
- Внутри блока сначала идёт **Предложение:** и полный предлагаемый текст, затем полный русский оригинал, тибетская цитата с латинской транслитерацией, английская цитата и **Обоснование:**. Цитаты оформляются через `>`.
- Перед исходными цитатами используются только короткие ссылки на источники: `[ru7]`, `[tib1]`, `[tib2]`, `[en]` и адрес соответствующего места (страница, при необходимости глава). Названия изданий здесь не повторяются.
- В `sources.md` каждый источник описывается одной строкой: `[ru7] - библиографические данные`. Сначала указываются автор, название, переводчики/редакторы, издание, место, издатель, год и доступные идентификаторы. Сведения о PDF или Kindle добавляются после библиографического описания. Неустановленные данные отмечаются явно; имя файла не заменяет описание текста. Между источниками — пустая строка. В начале строки допускается невидимый якорь `<a name="ru7"></a>` для ссылки `sources.md#ru7`.
- Пример ссылки в файле правки: `[\[ru7\]](sources.md#ru7), с. 1079 (PDF 299).`
- Номера файлов с правками соответствуют страницам `[ru7]`. «С.» обозначает страницу издания; «PDF» — порядковый номер страницы файла, начиная с первой. Для Kindle используется номер страницы, отображаемый в издании.
- Совпадающий тибетский фрагмент приводится один раз с адресами обоих изданий. Тибетское письмо сопровождается латинской транслитерацией по схеме Вайли без пометки «Wylie:»; для отдельного термина транслитерация стоит в скобках, для длинной цитаты — отдельным абзацем. Кириллическая транскрипция не используется.
- Основание проверки — тибетский текст. Английский перевод используется для сопоставления и также может содержать ошибки. Предложения проверяются до включения в итог; непроверенное не объявляется установленным.
- В полном предложении сохраняются части, которых данная правка не касается. Не добавляются авторские подписи и история общения агентов; обсуждение ведётся в PR.

- Сообщение коммита, заголовок и автоматически подготавливаемое описание PR совпадают с текстом `<summary>`: «исходный оборот» → «предлагаемая замена», без номера страницы и служебных слов. Подробности правки находятся в файле страницы.
