# Принятие и отклонение правок

Один PR посвящён одному законченному фрагменту текста. Предложение и его обоснование обсуждаются в PR; отдельные статусы в файл страницы не добавляются.

- **Влить PR** — принять правку. Её блок попадает в файл страницы в `main`.
- **Закрыть PR без слияния** — отклонить правку. Полное предложение и обсуждение сохраняются в закрытом PR.
- Открытый PR остаётся на обсуждении; в итоговый файл в `main` его предложение не попадает.

## Файл страницы

Сверху располагаются принятые правки в формате, описанном в [format.md](format.md). Перед ними нет заголовка «Принято», и в самих блоках нет пометок «Принято» или «Отклонено».

Внизу, после всех принятых правок, располагается раздел `## Отклонено:` с маркированным списком отклонённых предложений. Каждый пункт — текст summary и ссылка на соответствующий PR. Полный блок отклонённой правки сюда не переносится: цитаты, обоснование и обсуждение доступны по ссылке.

Если отклонённых правок нет, заголовок «Отклонено:» не выводится. Если на странице пока нет принятых правок, файл может содержать только раздел отклонённых.

## Автоматизация — следующий этап

Автоматизацию реализуем отдельно; сейчас этот документ фиксирует ожидаемое поведение.

При закрытии PR с правкой без слияния автоматизация добавляет в конец соответствующего файла страницы пункт раздела «Отклонено:». Решение определяется закрытием PR, вручную записывать статус или дублировать предложение в итоговый файл не требуется.

При слиянии PR блок принятой правки располагается выше раздела «Отклонено:». Повторная обработка одного события не должна создавать дубликаты ссылок.

Эти правила автоматизации относятся к PR с правками текста, а не к PR с источниками, форматом или обслуживанием репозитория. Обработку повторного открытия PR и технического закрытия (например, дубля) нужно определить перед реализацией автоматизации.
